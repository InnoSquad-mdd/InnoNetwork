# InnoNetwork 6.0.0 Release Notes

Status: Draft (unreleased)

Release date: TBD

This draft is not a published release and must not be used to create a
`6.0.0` tag.

## Highlights

- Promotes the operation-first client, immediate cancellation handle,
  bounded operation event stream, secure configuration façade, and value-only
  failure taxonomy from the temporary preview into the root module.
- Adds explicit replay-safety input so retry guidance is safe for HTTP method,
  idempotency, authentication, timeout, reachability, and status context.
- Adds realm-isolated authentication refresh, typed WebSocket message codecs,
  managed file-backed uploads, richer network-path snapshots, client-side
  rate limiting, and exporter-neutral semantic events.

## Breaking package changes

- Removes `InnoNetworkNext`; replace its product and import with
  `InnoNetwork`.
- Moves `InnoNetworkHLS`, `InnoNetworkHLSLive`,
  `InnoNetworkHLSAVFoundation`, and `InnoNetworkHLSAudio` to InnoStream while
  preserving their product and module names.
- A consumer using HLS must declare both InnoNetwork 6 and InnoStream 1, then
  change the HLS product's package owner to `InnoStream`.

See [Migration Guide: 6.0.0](../Migration-6.0.0.md) for exact manifest and
source changes.

## Release gates

- [ ] Documentation state is changed atomically from draft to ready.
- [ ] Public API allowlists remain exactly 1,407 declarations: 305 Stable,
  1,069 Provisionally Stable, and 33 SPI.
- [ ] Full root release preflight and all five Apple-platform builds pass.
- [ ] Capto and every known non-HLS main consumer build against the local
  candidate without relying on removed products.
- [ ] InnoNetworkProtobuf passes against the candidate and later against the
  published `6.0.0` tag.
- [ ] InnoNetwork `6.0.0` is published before InnoStream `1.0.0` attempts its
  clean remote-dependency release gate.
- [ ] Migrated HLS consumers resolve both published tags from a clean checkout.

InnoStream owns Apple HLS conformance, AVPlayer runtime, FairPlay, and HLS
module API gates after the split. InnoNetwork owns the bounded transport and
public companion contracts that InnoStream consumes.
